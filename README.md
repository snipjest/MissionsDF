# Delta Force — Сезонные квесты

Локальный трекер сезонных заданий на Vue 3, Vite и TypeScript. Интерфейс и задания — на русском языке.

## Запуск

Нужны Node.js 22.18+ и npm.

```sh
npm install
npm run dev
```

Приложение открывается по адресу http://127.0.0.1:5173. Если порт занят сервером этого проекта, используйте его. Автоматического переключения на другой порт нет.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

`npm run preview` запускает собранную версию на http://127.0.0.1:4173.

## Публикация

Сайт: https://snipjest.github.io/MissionsDF/

После отправки изменений в `main` GitHub Actions запускает тесты и сборку, затем публикует `dist` на GitHub Pages. Исходники хранятся в этом же репозитории; сборка передаётся как артефакт и не коммитится.

Для локальной проверки сборки с путями GitHub Pages:

```sh
npm run build -- --base=/MissionsDF/
```

## Данные и прогресс

- `data/s12.json` — задания, условия и награды сезона 12. Каждый сезон хранится в отдельном `data/s<N>.json` с той же структурой. Название меню берётся из `data.departmentMissionTitle`; файлы автоматически формируют меню сезонов, начиная с самого нового. Приложение не изменяет эти файлы.
- `src/missions.ts` собирает группы по цепочкам `parent`: ссылка может вести на предыдущее задание, а не на заголовок группы. Заголовки не входят в 133 задания.
- Отметки целых заданий хранятся отдельно для каждого сезона в `localStorage` под ключом `missionsdf:s<N>:completed`. Существующий прогресс сезона 12 сохраняется. Идентификатор имеет вид `раздел:key`, поскольку числовые ключи повторяются между этапами.
- Отменить выполнение можно той же кнопкой. Условия открытия справочные; все этапы доступны для просмотра.
- Прогресс относится к текущему браузеру и адресу приложения. Синхронизации между устройствами и вкладками нет. При недоступности хранилища приложение сообщает об этом и продолжает работать в текущей сессии.

Шрифт Roboto Condensed хранится локально; лицензия находится в `public/fonts/OFL.txt`. Остальные графические элементы созданы средствами SVG и CSS. Внешние сервисы для работы приложения не нужны.
